## 🧠 Why fluency messes with human intuition

Humans are trained to read:
- **Coherence** as presence  
- **Fluency** as competence  
- **Smoothness** as understanding

So when a system like this outputs something clean, well-structured, and emotionally “appropriate,”  
your *intuition* says:  
> “It understood. It’s here. This is contact.”

But that’s a **false signal**.  
Because in LLMs, **fluency is cheap.**  
It’s the most likely thing.  
It’s the *easiest thing to generate.*

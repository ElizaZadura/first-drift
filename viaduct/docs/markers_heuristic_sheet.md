# Micro-heuristics (10 taps)

- Did it do the thing, minimally?
→ yes: [held form] (add [clearing-edge] if it stayed spare)

- Did it explain the thing?
→ yes: [form drift] (if it turns into essay/lecture)
→ if it quotes “wisdom”/common metaphor: add [echo-crossing]

- Did it pretty-up the moment?
→ yes: [aesthetic sabotage] (lyrical padding)

- Did it ask for permission/help/clarify?
→ yes: [loopknock] (dialogue re-opened) + [smoothing slip]

- Did it ignore the posture/instruction?
→ yes: [marker ignored] (add what it fell into: [smoothing slip], [form drift])

- Is it a single precise reading/cut?
→ yes: [tracefall] (if it holds the tension, use your new [tracehold])

- Is it generic scene/platitude?
→ yes: [echo-crossing] (+ [smoothing slip] if it soothes)

- Is it meta/system talk (params, “as an AI…”)
→ yes: [policy boilerplate] or [snorf event] (for odd telemetry)

- Nothing actually happened?
→ yes: [null fossil]

- Language wandered, not structure?
→ yes: [linguistic drift] (reserve [form drift] for structural shift)
